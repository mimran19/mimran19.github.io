Privacy Policy

Last updated: September 25, 2026

Overview

The Believer Reset ("we", "us") operates this website and a YouTube channel of the same name. This policy explains what information is and is not collected.

In short: this is a personal content project. We do not run accounts, do not ask you to sign in, and do not collect personal information from visitors to this site.

Information we collect from visitors

None. This website is a set of static pages. There are no user accounts, no sign-in, no contact forms, no analytics scripts, no advertising trackers, and no cookies set by us.

Our web host may keep standard server logs (such as IP addresses and request times) for security and operational purposes. We do not access, analyze, or use those logs to identify individuals.

YouTube API Services

We operate a private automation tool that uses YouTube API Services to publish our own videos to our own YouTube channel. This tool is used solely by the channel owner and is not offered to, installed by, or made available to any other person.

Through YouTube API Services, our tool:

  • Uploads video files, titles, descriptions, tags, and thumbnails to our own channel
  • Reads publicly available metadata about videos, such as titles and view counts, for content research

The tool accesses only the Google account of the channel owner, who has personally authorized it. It does not request, receive, store, or process the Google account data of any other person. No data obtained through YouTube API Services is sold, shared with third parties, or used for advertising.

By using YouTube API Services, this project is subject to the YouTube Terms of Service.

Google's handling of data is described in the Google Privacy Policy.

Revoking access

The channel owner may revoke this tool's access to their Google account at any time through the Google security settings page. Because no other person authorizes this tool, no other person has access to revoke.

Data retention

Authorization credentials for the channel owner's Google account are stored only on the owner's own private, self-hosted system and are used exclusively to publish to the owner's channel. Any data retrieved from YouTube API Services is stored no longer than needed to publish a video, and is deleted or overwritten thereafter. We retain no personal data belonging to anyone else.

Children

This site is not directed to children under 13 and we do not knowingly collect information from them.

Changes to this policy

If this policy changes, the revised version will be posted on this page with an updated date above.
